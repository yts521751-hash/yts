# 金潮 JinChao

台股板塊金流觀測——把三大法人資金流向畫成泡泡圖，解讀板塊輪動。

## 功能

- **板塊輪動泡泡圖**：X＝近 5 日買賣超、Y＝相對 20 日均加速度、大小＝近 20 日金額（可縮放／拖曳）
- **四態篩選**：漲潮／輪動／觀望／退潮
- **成分股明細**：當日／近 5／近 20 日，外資／投信／自營分項
- **CP 值排行**、**大跌日逆勢買超**
- **白話小百科**、字級、淺／深色
- **每日自動同步**：伺服器啟動後，依排程自動抓證交所／櫃買盤後資料

## 資料來源（真實盤後）

- 上市：證交所三大法人買賣超日報 T86
- 上櫃：櫃買三大法人買賣明細
- 收盤價換算億元（股數 × 收盤價）
- 題材板塊成分為編輯定義
- 快取約 4 小時；失敗時回退示範資料並標「示範」

API：`GET /api/flow`（`?force=1` 強制重抓）

## 自動同步排程

預設（需 `npm run start` 或 `npm run dev` 持續運行）：

- **週一至週五**，台北時間 **18:00／18:30／19:00** 自動同步
- 畫面可按「強制更新」立刻重抓

可用環境變數調整：

```bash
# 自訂 cron（多組用 ; 分隔），時區預設 Asia/Taipei
SYNC_CRON="0 18 * * 1-5;0 19 * * 1-5"
SYNC_TZ="Asia/Taipei"

# 關閉自動同步
SYNC_DISABLED=1
```

## 本機執行

```bash
npm install
npm run dev
```

開啟 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

正式環境建議用 `npm run build && npm run start`，排程才會在背景持續執行。
