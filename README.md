# 金潮 JinChao

台股板塊成交金額觀測——用排行榜解讀題材板塊的成交熱度與輪動。

## 功能

- **成交金額排行榜**：可依當日、近 5 日、近 20 日成交、熱度、加速度、漲幅、CP 值排序
- **四態篩選**：放量／偏熱／偏冷／縮量（近 5 日日均 ÷ 近 20 日日均）
- **成分股明細**：當日／近 5／近 20 日成交金額與漲跌
- **CP 值精選**、**大跌日異常放量**
- **白話小百科**、字級、淺／深色
- **每日自動同步**：伺服器啟動後依排程抓盤後行情

## 資料來源

- 上市：證交所每日收盤行情（成交金額）
- 上櫃：櫃買每日收盤行情（成交金額）
- **不以三大法人買賣超計算**
- 題材板塊成分為編輯定義
- 快取約 4 小時；失敗時回退示範資料並標「示範」

API：`GET /api/flow`（`?force=1` 強制重抓）

## 本機執行

```bash
npm install
npm run dev
```

開啟 [http://127.0.0.1:43127](http://127.0.0.1:43127)。
