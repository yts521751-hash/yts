# 金潮 JinChao

台股板塊金流觀測網頁——以「潮汐」式板塊輪動解讀為基底的第一版：把三大法人資金流向畫成泡泡圖，一眼看出錢往哪個板塊流。

## 功能（v1）

- **板塊輪動泡泡圖**：X＝近 5 日買賣超、Y＝相對 20 日均的加速度、大小＝近 20 日金額；支援滾輪縮放、拖曳移動
- **四態篩選**：漲潮／輪動／觀望／退潮
- **板塊成分股**：點泡泡看個股當日／近 5 日買賣超，以及外資／投信／自營分項
- **CP 值排行**：資金流入多、漲幅仍相對溫和的板塊
- **大跌日逆勢買超**（或大盤未重挫時的「法人買最多」）
- **白話小百科**、字級切換、淺／深色主題

目前使用**示範資料**（標示「示範」），方便先把操作與解讀流程跑通；之後可替換成真實盤後資料源。

## 本機執行

```bash
npm install
npm run dev
```

瀏覽器開啟 [http://127.0.0.1:43127](http://127.0.0.1:43127)。
