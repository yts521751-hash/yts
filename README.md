# 金潮 JinChao

台股板塊金流觀測——把三大法人資金流向畫成泡泡圖，解讀板塊輪動。

## 功能

- **板塊輪動泡泡圖**：X＝近 5 日買賣超、Y＝相對 20 日均加速度、大小＝近 20 日金額（可縮放／拖曳）
- **四態篩選**：漲潮／輪動／觀望／退潮
- **成分股明細**：當日／近 5／近 20 日，外資／投信／自營分項
- **CP 值排行**、**大跌日逆勢買超**
- **白話小百科**、字級、淺／深色

## 資料來源（真實盤後）

- 上市：證交所 [三大法人買賣超日報 T86](https://www.twse.com.tw/zh/trading/historical/t86.html)
- 上櫃：櫃買三大法人買賣明細
- 收盤價：證交所 MI_INDEX、櫃買 OpenAPI 收盤行情
- 金額＝買賣超股數 × 當日收盤價（單位：億元）
- 題材板塊成分為編輯定義（非官方產業分類）
- 伺服器端快取約 4 小時；首次載入需抓近 20 個交易日，約 1～2 分鐘
- 若外部網站失敗，會自動回退示範資料並標示「示範」

API：`GET /api/flow`（`?force=1` 強制重抓）

## 本機執行

```bash
npm install
npm run dev
```

開啟 [http://127.0.0.1:43127](http://127.0.0.1:43127)。

## 技術

Next.js（App Router）+ TypeScript + Tailwind + shadcn/ui + 自製 SVG 泡泡圖
